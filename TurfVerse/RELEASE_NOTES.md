# Release Notes

## TurfVerse 1.0.0 MVP (Build 1)

Initial MVP release candidate.

### Included

- Premium responsive Flutter UI with role-based navigation
- Supabase email/password authentication and profile management
- Player dashboard, cricket profile, and stats placeholders
- Turf discovery, slot browsing, manual-payment bookings, and cancellation
- Open match creation, joining, participants, and simple comments
- Team creation and captain-managed membership
- Turf owner turf, slot, booking, and revenue management
- Role-gated admin overview and report resolution
- Privacy, terms, support, issue reporting, and deletion-request screens

### Known Limitations

- Payments and settlement are manual placeholders.
- Turf images and team logos use placeholders.
- Account deletion requests require manual admin processing.
- Match chat is not real time.
- Email confirmation requires a server-side profile creation flow before use.
- Invitations, tournaments, auctions, notifications, and advanced analytics are
  not included.
