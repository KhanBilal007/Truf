# Store Compliance Checklist

## Implemented In App

- [x] Privacy Policy screen exists.
- [x] Terms and Conditions screen exists.
- [x] Delete Account request screen exists.
- [x] Contact Support and Report Issue screens exist.
- [x] Account deletion requests are recorded without exposing admin credentials.
- [x] No gambling, betting, or fantasy-money features exist.
- [x] No misleading AI claims are made.
- [x] No unnecessary device permissions are declared.
- [x] No real API keys are hardcoded or committed.
- [x] App display name is TurfVerse.
- [x] Initial version is `1.0.0+1`.
